5 Recursive CTE over unparameterized numeric loses precision: convert_recursive_cte_results (types.rs:830) builds CAST(x AS numeric) = affinity cast in the SQLite dialect. Any type with a KEY and a '<' outside the fixed table hits it: sort by KEY when the type has one.
